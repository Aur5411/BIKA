# BIKA · 个人修改版

基于 [shizq123/BIKA](https://github.com/shizq123/BIKA) 修改。
这里只记录本修改版的功能改动，原项目介绍请看原仓库。

## 关于软件更新

本版本**已彻底移除应用内更新**：不检查更新、不弹提示、不连网。
本仓库不提供更新，需要新版本请前往原仓库：**https://github.com/shizq123/BIKA**

## 版本与成品包

`com.shizq.bika` · 官方发布证书签名（`CN=shizq`），可与官方版本互相覆盖安装。
V1 + V2 + V3 三种签名方案，兼容最老的系统与校验工具。成品包见下方「下载」。

## 功能亮点

- **图片提速**：强制 HTTP/1.1 多连接（h2 被 CDN 限速，实测差 20～60 倍）；
  竞速选出最快源并自动改写；连接预热（启动即预热 16 条，封面和首图不再等握手）；
  全局节流闸门防 429 判死；内存 + 磁盘缓存补齐（此前每次冷启动都要重下所有图）
- **修复图片无法加载**：查明 `tobs/` 是后端选择段，唯一能兜住无 `tobs/` 路径的
  真源站 `storage-b.diwodiwo.xyz` 排候选池首位；路径里五类不可见字符自动归一化，
  失败时还能退回服务端原样路径自愈；冷启动首图直连兜底源，省掉 900ms 白等
- **启动 / 详情页提速**：详情一到就渲染、推荐后台补（省掉最多 1.5s）；
  启动数据提前收集；主线程磁盘写挪后台
- **章节目录**：并发翻页；服务端截断时按序号补出缺失章节；边拉边显示，
  第一个来回就铺出前 20 话
- **其它**：分流线路自动探测、榜单 10 分钟缓存、阅读器上下章判定修正、
  下载进度与阅读进度修复等
