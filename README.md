## 新增与改动

**章节目录**

- 修复 100 话以上只加载出二三十话：并发翻页 + 整体超时 + 5 分钟缓存 + 不轻信服务端空页
- 服务端截断时按章节序号补出缺失的前置章节（占位标题形如「第 12 話」），可直接点开阅读
- 边拉边显示：第一个网络来回就铺出前 20 话，不再整屏转圈；失败仍整份报错，不展示残缺列表
- 新增按钮：回到顶部 / 回到底部 / 正序倒序（连同原下载共四个，同尺寸同配色），
  两个滚动按钮同一组显隐、动画不互相打断
- 顶部信息行写明状态：「共 160 话 · 最新话在前」，加载中显示「已加载 20 话 …」

**首页** 移除顶部「最近浏览漫画」（设置页未动）。

**分流 / 网络** 冷启动自动探测并切到最低延迟线路（API 与图片成对选取）；设置页测完延迟
自动应用最低延迟 IP；IP 分流增强（多 IP 边缘池、并发探测、失效黑名单、按 `/24` 归并、快照兜底）。

**图片加载** 补上缺失的图片磁盘缓存（Coil 不会自动创建），此前每次冷启动都要重下所有封面。
现在内存缓存 20%，磁盘缓存按可用空间 2% 自适应（64 MB ～ 512 MB）。

**榜单** 加 10 分钟缓存，从漫画返回榜单不再重新转圈。

**其它** 修复下载完成后进度不置 100；修复阅读进度防抖写入会把进度写退；详情页标签改惰性列表；
补齐多个模块缺失的测试依赖，416 项单元测试全部通过。
